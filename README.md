# Focus: задачи, заметки, хранилище

Одно приложение вместо Things, TickTick, Notion и заметок iPhone. Сейчас в репозитории этап 1 из ТЗ (MVP, веб, только владелец).

## Стек

- Next.js 16 (App Router, Server Actions), React 19, TypeScript, Tailwind CSS 4
- PostgreSQL + Drizzle ORM (миграции в `drizzle/`)
- Claude API (`@anthropic-ai/sdk`) для разбора быстрого и голосового ввода; без ключа работает встроенный парсер на правилах
- Vitest для юнит-тестов

## Запуск

```bash
cp .env.example .env.local     # DATABASE_URL, по желанию ANTHROPIC_API_KEY
npm install
npm run db:migrate             # нужен DATABASE_URL в окружении
npm run dev
```

Откройте http://localhost:3000/signup. При регистрации создаются аккаунт (workspace) и четыре стартовые области.

Проверки: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.

## Что сделано (этап 1)

| Область | Что есть |
| --- | --- |
| Структура | Области → проекты → задачи → подзадачи (1 уровень), теги, статусы проектов |
| Задачи | Все поля из ТЗ: статус, P1–P4, дата начала, дедлайн, время, исполнитель, теги, «Личное», описание |
| Повторы | Дни/недели/месяцы/годы с интервалом, дни недели, «2-й вторник», «последний рабочий день», режим «после выполнения», окончание по дате или числу раз; подзадачи копируются в новое повторение |
| Виды | Фокус (топ-3, просроченное и P1, лента по времени, счётчик Inbox, «Жду ответа»), Входящие, Сегодня, Предстоящее на 14 дней, Когда-нибудь, Журнал с поиском |
| Быстрый ввод | Строка на каждом экране (клавиша `n`), предпросмотр распознанных полей, голос через Web Speech API, несколько задач в одной фразе (с ИИ) |
| ИИ | Разбор фразы на поля; если ИИ не уверен, задача падает во Входящие с предложением «Принять / Отклонить»; кнопка «Разобрать с ИИ» для всего Inbox |
| Заметки | Блоки (текст, заголовки, списки, чек-листы, цитаты, разделители, фото), markdown-шорткаты, «→ в задачу» с обратной ссылкой, привязка к области/проекту, закрепление, поиск |
| Платформа | Адаптивная вёрстка, PWA-манифест, RU/EN интерфейс, часовой пояс пользователя, журнал действий |
| Мультиарендность | `workspace_id` в каждой таблице, каждый запрос и action ограничен workspace текущей сессии |

## Чего пока нет

- Офлайн-режим и push-уведомления (нужен service worker), напоминания
- 2FA, восстановление пароля
- Роли ассистентов, канбан, календарь, хранилище с шифрованием (этап 2)
- Планирование дня ИИ, вопросы по задачам, видео/голос/OCR в заметках, импорт (этап 3)
- Файлы хранятся в Postgres; перед запуском для других пользователей перенести в объектное хранилище

## Структура

```
src/app/(app)/        страницы приложения (Фокус, виды, области, проекты, задачи, заметки)
src/app/(auth)/       вход и регистрация
src/app/actions/      server actions: задачи, заметки, структура, auth
src/app/api/files/    загрузка и выдача фото
src/db/schema.ts      схема БД
src/lib/recurrence.ts правила повторов (покрыто тестами)
src/lib/quick-parse.ts парсер быстрого ввода на правилах (покрыто тестами)
src/lib/ai-parse.ts   разбор через Claude
src/lib/queries.ts    выборки для видов
```
